# 🍽️ Market Fix — AI Marketplace заведений Алматы

AI-Marketplace для подбора, сравнения и бронирования заведений Алматы:
рестораны, кафе, бары, пабы, караоке и event-площадки.

Ключевое отличие — **AI-подбор**: пользователь описывает потребность текстом,
а движок подбирает наиболее подходящие заведения по сценарию, бюджету, кухне,
атмосфере и инфраструктуре.

![Market Fix](assets/logo.png)

---

## 🚀 Возможности

- **🤖 AI-подбор (чат)** — стартовый экран. Введите запрос вида
  *«Уютное место для свидания на двоих, до 20 000 ₸, с парковкой»*,
  и AI вернёт топ-N заведений с объяснением выбора.
- **🍽️ Каталог** — 50 заведений с умными фильтрами: категория, кухня, район,
  ценовой сегмент, инфраструктура (Wi-Fi, парковка, терраса, дети, VIP),
  сценарий, бронирование, AI score.
- **📊 Аналитика рынка** — распределение по категориям, ценам, кухням, районам,
  покрытие сценариев, топ-15 по AI score.
- **🎯 Детальные карточки** — адрес, контакты, рейтинг 2ГИС, график работы,
  меню, матрица сценариев 0–5, плюсы/ограничения, источники.

## ⚙️ Два режима данных

| Режим | Источник | Когда использовать |
| :-- | :-- | :-- |
| **Built-in** 📦 | `venues_data.py` (50 заведений) | По умолчанию, без настройки БД |
| **API** 🔌 | Supabase (таблица `venues`) | Production, собственные данные |

Переключатель находится в боковой панели. Если Supabase недоступен,
приложение автоматически откатывается к Built-in.

## 🛠️ Установка и запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. (Опционально) настроить Supabase — скопировать .env
cp .env.example .env  # затем вписать свои ключи

# 3. Запустить
streamlit run streamlit_app.py
```

Приложение откроется на http://localhost:8501.

---

## 🗄️ Настройка Supabase (API-режим)

1. Создайте проект на https://supabase.com.
2. Откройте **SQL Editor** и выполните последовательно:
   - `supabase/migrations/001_initial_schema.sql` — создание таблиц.
   - `supabase/seed.sql` — загрузка 50 заведений (сгенерировать: `python seed_supabase.py`).
3. Укажите ключи в `.env`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

4. Переключите режим в боковой панели на **API (Supabase)**.

## 🎯 AI Matching — как работает подбор

**Финальный балл матча (0–100):**

```
match = 0.55 × scenario_fit (0–5 → 0–100)
      + 0.25 × ai_score      (0–100)
      + 0.20 × keyword_bonus (0–100)
```

- **scenario_fit** — оценка заведения по запрошенным сценариям
  (свидание, семья, бизнес, друзья, банкет, турист и т. д.).
- **ai_score** — предварительная ценность заведения для marketplace:
  `0.20·P + 0.15·R + 0.10·D + 0.15·B + 0.10·U + 0.15·S + 0.15·M`.
- **keyword_bonus** — совпадение по кухне, атмосфере, цене, инфраструктуре, району.

Парсер запроса распознаёт ключевые слова на русском и английском:
*свидание, романтик, семья, бизнес, банкет, турист, Wi-Fi, терраса, парковка,
до 20000 ₸, итальянская, грузинская, суши, коктейли…*
