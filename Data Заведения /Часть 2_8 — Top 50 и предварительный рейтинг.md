# Часть 2/8 — Top 50 и предварительный рейтинг

## 1. Важное уточнение

Предыдущий список из 50 заведений был **рабочим shortlist**, а не полностью проверенной базой. В нём были аналитические гипотезы, которые нельзя использовать в production без проверки по 2GIS, официальному сайту и актуальному меню.

Ниже — переработанная версия рейтинга. Значения `AI score` являются **предварительными аналитическими баллами**, а не окончательными оценками. Точные рейтинги 2GIS, Google, адреса, цены, часы работы и бронирование будут внесены после проверки карточки каждого филиала.

## 2. Источники отбора

В качестве источников shortlist использовались:

- Restolife Top 100 — рейтинг заведений Алматы на основе данных 2GIS, Яндекс Карт, Google Maps и RestoLife. В методике Restolife количество оценок группируется по уровням популярности: от 2 000+ до 15 000+ оценок. cite[^1]
- Tripadvisor — пользовательские отзывы, популярность страницы, кухни, ценовые категории и туристическая востребованность. cite[^2]
- Ultima Guide — отдельные рейтинги и longlist ресторанов и баров Алматы, сформированные на основе пользовательских и алгоритмических сигналов. cite[^3]
- Restoran.kz — подборки с учётом рейтингов, отзывов и количества бронирований. cite[^4]
- The World’s 50 Best Discovery — международный сигнал узнаваемости отдельных алматинских проектов. cite[^5]


## 3. Формула рейтинга

$$
AI\ Score =
0.20P +
0.15R +
0.10D +
0.15B +
0.10U +
0.15S +
0.15M
$$


| Компонент | Вес | Что измеряет |
| :-- | --: | :-- |
| Popularity | 20% | Известность, отзывы, частота упоминаний |
| Rating/reviews | 15% | Рейтинг с поправкой на объём отзывов |
| Data completeness | 10% | Наличие адреса, меню, цен, контактов и графика |
| Booking potential | 15% | Возможность забронировать стол или площадку |
| Variety / uniqueness | 10% | Уникальность кухни, концепции или формата |
| User scenario coverage | 15% | Количество сценариев, которые покрывает заведение |
| Marketplace potential | 15% | Ценность для AI-рекомендаций и коммерческого marketplace |

`AI score` не означает «лучший ресторан». Это оценка того, насколько объект полезен как элемент каталога AI Marketplace.

### Исправление по ALM-050

`Dragonfly Izakaya` пока нельзя считать подтверждённым элементом Top 50 без отдельной проверки карточки в 2GIS или официального источника. До такой проверки эта строка должна иметь статус `candidate`, а не `verified`.

Аналогично, строка `ALM-043B` не должна оставаться в финальной базе как безымянное заведение. Она является техническим placeholder и должна быть заменена конкретным объектом из подтверждённого longlist Ultima Guide либо Restolife. В production-версии такие строки будут удалены.

## 9. Источники, которые необходимо получить для каждой карточки

Для окончательной версии каждой строки потребуется минимум:

```text
2GIS URL
official website URL
official Instagram URL
Google Maps URL, if available
Tripadvisor URL, if available
menu URL
booking URL
last_verified_at
verification_status
```

Критические поля нельзя заполнять только по агрегатору. Например, Restoran.kz указывает, что в Алматы доступны сотни ресторанов с меню, отзывами, фотографиями и возможностью бронирования, однако такие данные нужно дополнительно сверять с филиалом и официальным меню. cite[^6]

## 10. Предварительный вывод

Наиболее ценными для первой версии являются не обязательно самые дорогие и не обязательно самые высоко оценённые рестораны. Для marketplace важнее сочетание:

- узнаваемого бренда;
- понятного сценария выбора;
- доступного бронирования;
- подтверждённого меню;
- устойчивого локального спроса;
- разнообразия цен и кухонь;
- возможности сравнивать альтернативы.

В следующей части нужно перейти к **расширенным карточкам ALM-001–ALM-017**. Для каждой карточки необходимо отдельно проверить адрес, филиал, контакты, рейтинги, актуальное меню, цены, график, бронирование, инфраструктуру и источники.
